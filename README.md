# Godot Survivor Lab

一个用“邪修”方式学习 Godot 的极简 2D 幸存者游戏项目。

## 目标
不先系统学习全部 Godot，而是用一个可玩的 Vampire-Survivors-like Demo 驱动学习。
每 20–40 分钟完成一个肉眼可见的小功能，并用 Git 保留可回退版本。

## 技术栈
- Godot 4.7.2 stable
- GDScript
- 2D Pixel Art
- Git + GitHub
- Windows first

## First Playable
- WASD 移动
- 怪物生成与追踪
- 自动攻击
- 击杀掉落经验
- 升级三选一
- 死亡与重新开始
